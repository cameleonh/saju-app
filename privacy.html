결로 돌아가기

개인정보 처리방침

작성일: 2026년 8월 5일

현재 출시 상태
계정 저장 기능은 운영자의 법적 명칭, 전용 개인정보 문의 채널, 최종 위탁·국외이전 고지와 법률 검토가 완료될 때까지 공개하지 않습니다. 현재 명식 기록은 이용자의 브라우저 안에만 저장됩니다.

1. 처리 원칙

결은 사주 계산과 자기 성찰을 돕는 참고 서비스를 제공합니다. 필요한 범위보다 많은 정보를 모으지 않으며, 커플·상대방 정보와 만 19세 미만 이용자의 명식은 서버에 저장하지 않습니다. 입력값을 광고, 마케팅 또는 모델 학습에 사용하지 않습니다.

2. 현재 처리하는 정보

구분항목목적·보관
기기 기록입력한 출생정보, 계산 결과, 이용자가 작성한 질문브라우저 IndexedDB에 저장됩니다. 서버로 동기화하지 않으며 이용자가 기록함에서 직접 삭제할 수 있습니다.
계산 요청음력 변환 등에 필요한 날짜·시각 값요청 처리 중 일시적으로 사용하며 요청 본문을 애플리케이션 로그에 남기지 않습니다.
접속·보안 기록접속 시각, HTTP 방식, 쿼리 문자열을 제외한 요청 경로, 응답 상태와 크기서비스 안정성과 침해사고 대응을 위해 최대 90일 보관합니다. IP 주소, 브라우저 식별정보, 참조 페이지, 쿠키, 로그인 코드와 요청 본문은 접근 로그에 남기지 않습니다. 과도한 요청을 막을 때 접속 주소는 프로세스마다 바뀌는 임시 식별값으로 즉시 변환하며 2분 이내 메모리에서 지웁니다.

3. 계정 저장 기능이 공개될 때 추가되는 처리

계정 저장은 이메일 확인을 마친 만 19세 이상 이용자가 본인의 단일 명식을 저장할 때만 작동합니다. Amazon Cognito가 이메일 인증을 처리하며, 서비스 DB에는 Cognito 식별자와 비밀키 기반 이메일 확인값, 내부 계정 UUID, 암호화된 출생정보와 계산 결과가 저장됩니다. 이메일 원문, 비밀번호, 세션 토큰 원문은 서비스 DB에 저장하지 않습니다.

핵심 계정 저장은 이용자가 요청한 저장·삭제·기기간 이용 기능을 제공하기 위한 처리로 문서화합니다. 선택적 마케팅이나 학습 목적의 동의 항목은 제공하지 않습니다.

4. 보유기간과 파기

  • 브라우저 기록: 이용자가 직접 삭제하거나 브라우저 저장소를 지울 때까지
  • 계정 저장 기록: 이용자가 개별 기록을 삭제하거나 계정을 폐쇄할 때까지
  • 삭제 요청: 활성 DB에서 24시간 이내 삭제, Lightsail 관리형 DB 복구 백업에서 최대 7일 이내 만료
  • 인증·보안 로그: 최대 90일

법령상 보존 의무나 진행 중인 분쟁·보안사고가 있으면 해당 목적에 필요한 최소 정보만 분리하여 보관하고 기간이 끝나면 파기합니다.

5. 처리위탁과 국외 처리

계정 저장 기능에는 Amazon Web Services의 서울 리전 Lightsail 관리형 PostgreSQL, Cognito, KMS가 사용될 예정입니다. AWS는 인프라 운영 과정에서 공개된 하위처리자와 글로벌 지원체계를 사용할 수 있습니다. 최종 수탁자, 이전 국가·시기·방법, 목적, 보유기간, 거부 방법과 효과를 확인하여 고지하기 전에는 계정 저장 기능을 공개하지 않습니다.

6. 안전조치

출생정보는 KMS 기반 봉투 암호화로 필드 단위 암호화하고, DB 전송구간 TLS, 최소권한 DB 역할, 사용자별 RLS, 원문이 없는 세션 토큰 해시, 접근 로그 최소화, 일일 백업과 복구 점검을 적용합니다. 암호화 키와 DB 자격증명은 소스 저장소에 넣지 않습니다.

7. 이용자의 권리

브라우저 기록은 데이터 안내 화면에서 열람·내보내기·삭제할 수 있습니다. 계정 저장 기능이 공개되면 계정 화면에서 열람, 개별 삭제, 전체 삭제와 탈퇴를 제공하며, 전용 개인정보 문의 채널도 이 문서에 함께 공개합니다.

8. 미성년자와 상대방 정보

만 19세 미만 이용자의 계정 저장을 제공하지 않습니다. 커플 명식은 상대방의 동의를 확인한 경우에도 이 기기 안에서 계산·저장하며 계정 저장소에 제출하지 않습니다. 음력 변환을 선택하면 제2항과 같이 날짜·시각만 요청 처리 중 일시 사용합니다. 타인의 정보를 허락 없이 입력하거나 불이익을 주는 데 이용해서는 안 됩니다.

9. 자동수집 장치

현재 광고·추적 쿠키를 사용하지 않습니다. 계정 기능이 공개되면 로그인 상태 유지를 위해 필수 HttpOnly 세션 쿠키만 사용하며, 이 쿠키는 최대 1시간 후 만료됩니다.

10. 운영자와 문의

운영자의 법적 명칭과 전용 개인정보 권리 문의 채널은 계정 저장 공개 전에 이 항목에 고지합니다. 해당 정보가 없는 동안에는 계정 저장 기능을 제공하지 않습니다.

11. 변경 안내

처리 항목, 위탁사, 보유기간 또는 이용자 권리에 중요한 변경이 있으면 적용 전에 서비스 화면에서 알립니다.
