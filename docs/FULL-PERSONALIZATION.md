# Full Personalization Architecture
# 완전 개인화 리딩 시스템 설계

> 결정일: 2026-08-05
> 목표: "최고의 서비스" — 모든 사용자의 명식에 대해 개인화된 혜민 수준 리딩

## 핵심 통찰: 모듈식 조합

모든 조합(일간×월지×일지×시주×대운×성별×연령 = 천문학적)을 정적 DB로 만들 수 없다.
대신 텍스트를 **독립적인 모듈로 분해**하고, 사용자 명식에 맞춰 조합한다.

혜민 샘블 분석 결과, 텍스트 기여도:
- 일간×연운 (Base): 60% → **30패턴 완료** (8,100블록)
- 월지 (Seasonal): 20% → **신규 생성 필요**
- 대운 (Lifecycle): 12% → **신규 생성 필요**
- 충·합 (Interaction): 5% → 규칙 기반 처리
- 성별/연령/직업 (Personal): 3% → 규칙 기반 톤 조정

## 아키텍처

```
┌─────────────────────────────────────────────────┐
│ Layer 0: Engine (기존)                          │
│   natal-engine → pillars[4], dayMaster, etc.   │
│   daewoon-engine → cycles[8], current cycle    │
│   annual.mjs → yearFacts, tenGod, relations     │
└───────────────────┬─────────────────────────────┘
                    ▼
┌─────────────────────────────────────────────────┐
│ Layer A: Pattern Modules (정적 DB)              │
│                                                 │
│  A1. Base (일간×연운):     30패턴 × 270블록     │
│      → 완료 ✓                                   │
│                                                 │
│  A2. Month (일간×월지):    120패턴 × 13항목     │
│      → 월지별 계절·격국 기조 모듈               │
│      → LLM 일괄 생성                            │
│                                                 │
│  A3. Daewoon (대운×십신):  60갑자×10간 × 8항목  │
│      → 현재 대운의 10년 주기 테마               │
│      → LLM 일괄 생성                            │
│                                                 │
│  A4. Interactions (충·합·형·파):               │
│      → 규칙 기반 생성 (DB 불필요)               │
└───────────────────┬─────────────────────────────┘
                    ▼
┌─────────────────────────────────────────────────┐
│ Layer B: Composer (동적 조합 엔진)              │
│                                                 │
│  입력: 사용자 명식 전체                         │
│    - 일간, 월지, 일지, 시주                     │
│    - 대운 (현재 + 다음)                          │
│    - 연운 (해당 년도)                           │
│    - 성별, 나이, 출생지                          │
│                                                 │
│  처리:                                          │
│    1. A1에서 일간×연운 베이스 모듈 선택         │
│    2. A2에서 월지별 계절 모듈 선택/병합         │
│    3. A3에서 대운 테마 모듈 선택/병합           │
│    4. A4 규칙으로 충·합 수정사항 적용           │
│    5. 개인 정보로 톤/처방 조정                  │
│                                                 │
│  출력: 개인화된 8카드 + 13항목 + 24슬롯         │
└───────────────────┬─────────────────────────────┘
                    ▼ (선택적)
┌─────────────────────────────────────────────────┐
│ Layer C: LLM Polish (로컬 Qwen)                 │
│                                                 │
│  입력: Layer B의 조합된 텍스트                  │
│  처리: 자연스러운 문장으로 다듬기 (seed 고정)    │
│  출력: 최종 사용자 텍스트                       │
│                                                 │
│  프라이버시: 생년월시 전송 없음                 │
│  재현성: prompt seed 고정 → 같은 입력=같은 출력  │
└─────────────────────────────────────────────────┘
```

## Layer B Composer 규칙 (예시)

```
사용자: 무토 일간, 묘월 생, 2025년 을사년, 현재 대운 임술

1. Base 선택: 무_을_사 패턴 (이미 있음)
   → 8카드 + 13항목 + 24슬롯 베이스

2. Month 병합: 무토×묘월 모듈
   → "봄의 무토는 얼어있던 땅이 녹는 시기" 테마 추가
   → health: "간·담 주의, 봄철 피로" 세부 처방
   → career: "새싹이 돋듯 새 방향 시도에 유리"

3. Daewoon 병합: 임술 대운 모듈
   → "물이 흐르다 둑을 만나는 10년" 테마
   → 재물: "들어오는 물이 둑에 막혀 고이는 시기"
   → 관계: "넓은 인맥이 형성되나 안정감 필요"

4. 충·합 수정: 원국 자(日) × 연운 사(巳) → 없음 (원국 지지와의 관계)
   → 충 있으면: "...변화와 긴장이 예상됩니다" 추가
   → 합 있으면: "...협력할 수 있는 흐름" 추가

5. 개인 조정:
   → 여성 35세: "30대 중반의 중요한 전환기" 톤
   → 직업 있으면: career 항목에 맞춤 조언
```
