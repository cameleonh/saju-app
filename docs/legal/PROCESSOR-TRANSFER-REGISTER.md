# Processor and Transfer Register

Status: launch-blocking draft.

| Provider/service | Task | Primary region/data | Contract evidence required |
|---|---|---|---|
| Amazon Web Services, Lightsail managed PostgreSQL | Managed database, TLS, seven-day PITR | `ap-northeast-2` (Seoul) | AWS customer agreement/DPA, service terms, current subprocessor list |
| Amazon Web Services, KMS | Root key and data-key operations | `ap-northeast-2` | Key policy, CloudTrail evidence, DPA/subprocessor review |
| Amazon Web Services, Cognito | Email account verification and identity tokens | `ap-northeast-2` | User-pool configuration, message delivery path, DPA/subprocessor review |
| Amazon Web Services, Lightsail instance | Application and security logs | `ap-northeast-2` | Instance access register, snapshot settings, incident owner |

No external AI, analytics, advertising, payment, SMS, or marketing processor is approved.

Before cloud save is public, counsel must record whether AWS global support/subprocessors create an overseas transfer, and complete the statutory notice fields: recipient, country, timing/method, data, purpose, retention, refusal method, and refusal effect. A Seoul storage setting alone is not proof that no overseas processing occurs.
